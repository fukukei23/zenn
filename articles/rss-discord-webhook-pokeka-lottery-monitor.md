## はじめに

「お目当ての商品の抽選受付が始まったのに気づくのが遅くて、買いそびれてしまった……」

こうした悩みを解決するために、ニュースサイトなどのRSSを監視し、新しい情報が公開されたらすぐにDiscordへ通知してくれるツール「pokeka-lottery-monitor」を開発しました。

本記事では、このツールの開発実例をもとに、**「RSSの集約」「ノイズを削ぐフィルタリング」「環境変数を用いた安全な設計」**という、自動監視ツールを作るための基本的な考え方を初心者向けに丁寧に解説します。Pythonを使った簡単なコード例も交えながら進めるので、自動化ツールを自作してみたい方はぜひ参考にしてみてください。

## 1. 複数のRSSを集約し、重複を排除する

自動監視ツールの第一歩は、情報源（RSS）の取得です。ポイントは、複数の情報源からデータを集め、一番重要な情報だけを絞り込むことです。

本ツールでは、GoogleNewsが提供する複数のRSSクエリ（例えば「イオン」「Joshin」「受付開始」といったキーワードの組み合わせ）を主力として利用しています。取得したRSSのデータの中から、不要なサイト（ノイズになりやすい特定の情報サイトなど）を除外し、本当に知りたい「抽選情報」にフォーカスします。

また、複数のRSSをまたぐと、同じニュースが何度も引っかかってしまい、Discordの通知がスパムのようになってしまいます。これを防ぐために、**「重複排除」**の仕組みが不可欠です。

すでに通知した記事のリンク（URL）をリストやデータベースに保存しておき、新しく取得した記事のURLと照らし合わせることで、未通知の記事だけを抽出します。これにより、ユーザーにストレスを与えないクリーンな通知を実現できます。

## 2. 「価格閾値フィルタ」で本当に欲しい情報だけを残す

情報を取得できても、「お菓子のおまけとして1パックだけ付いてくる商品」や「数百円の単品パック」の通知が毎回届くのは鬱陶しいものです。そこで本ツールでは、**「価格閾値（しきいち）フィルタ」**という仕組みを導入しました。

具体的には、取得した記事のタイトルや説明文から価格情報を readし、以下のようなルールを設定しています。

- **1000円未満の単品パックは除外する**
- **BOXやデッキセットなどの高額セットは残す**

このフィルタリングを行うことで、「当たり前の日用品」のようなノイズを削ぎ落とし、「今回絶対に申し込みたい高価な抽選商品」だけをピンポイントで通知できるようになります。

実務においても、単にデータを集めるだけでなく「ユーザー（あるいは自分自身）にとって本当に価値のあるデータだけを抽出するロジック」を組み込むことが、ツールの実用性を大きく高めます。

## 3. 新PC移行にも強い「環境変数管理」とは？

初心者がツール開発で最もつまずきやすく、かつ後悔しやすいのが「ハードコーディング（パスワードやファイルの保存場所を、直接コードの中に書き込んでしまうこと）」です。

WebhookのURLや、自分のPCのローカルパス（`/home/...` など）を直接コードに書き込んでしまうと、以下のような問題が発生します。

1. GitHubなどにコードを公開した際、WebhookのURLが世界中にバレてしまう
2. 新しいPCに買い替えたり、別の環境に移行した際に、コードの中身を書き直さなければならない

これを防ぐために、本ツールでは **`secrets.env` というファイルに機密情報を一元化** し、Pythonからは環境変数として読み込む設計にしています。

以下は、環境変数を読み込み、DiscordのWebhookにメッセージを送信するPythonのシンプルな実装例です。

```python
import os
import requests
from dotenv import load_dotenv

# secrets.envから環境変数を読み込み
load_dotenv('secrets.env')

# 環境変数からWebhook URLを取得（直接コードには書かない）
WEBHOOK_URL = os.getenv('DISCORD_WEBHOOK_URL')

def send_discord_notification(title: str, url: str, price: str = None):
    """
    Discordに通知を送る関数
    """
    if not WEBHOOK_URL:
        print("エラー: Webhook URLが設定されていません。")
        return

    # DiscordのEmbed（埋め込み）形式でメッセージを装飾
    embed = {
        "title": title,
        "url": url,
        "color": 5814783, # 適当な色（10進数）
    }
    
    if price:
        embed["fields"] = [{"name": "価格情報", "value": price, "inline": True}]

    payload = {"embeds": [embed]}
    
    try:
        response = requests.post(WEBHOOK_URL, json=payload)
        response.raise_for_status()
        print("通知を送信しました！")
    except Exception as e:
        print(f"通知エラー: {e}")

# 実行例
if __name__ == "__main__":
    send_discord_notification(
        title="【抽選開始】ポケモンカード 高額セット商品",
        url="https://example.com/lottery-start",
        price="5,000円"
    )
```

このように `os.getenv()` を使って変数を読み込むようにしておけば、`secrets.env` ファイルをGitの管理外（`.gitignore`）に設定しておくだけで、セキュリティを保ったままコードを安全に公開できます。また、PCを移行する際も、新しい環境で `secrets.env` を用意するだけで済み、コード本体は一切書き換える必要がありません。

## おわりに

本記事では、実際に開発した「pokeka-lottery-monitor」の実例をもとに、以下の設計思想を紹介しました。

1. **複数RSSの集約と重複排除** によるストレスフリーな通知
2. **価格閾値フィルタ** による本当に欲しい情報だけのピックアップ
3. **環境変数管理** によるセキュアで移行しやすいコード設計

「自動化ツール」と聞くと難しく感じるかもしれませんが、やっていることは「データを取得する」「条件で分岐する」「通知を飛ばす」というシンプルな組み合わせです。まずは小さなスクリプトを動かし、少しずつフィルタリングの条件を足していくのが、初心者におすすめのアプローチです。
