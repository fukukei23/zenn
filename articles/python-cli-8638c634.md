## はじめに

自分のClaude Code環境には、`rm -rf` のような危険なコマンドを実行前に自動ブロックする「ガード機構」をフックとして置いています。先日、このガードが**完全に正常なコマンドまでブロックする**事故が起きました。

原因を追ってみると、犯人はたった数文字の正規表現――**貪欲マッチ（greedy match）の `.*`** でした。この記事では、事故の再現から修正、テストによる再発防止までを初心者向けにまとめます。「正規表現はなんとなく書ける」というレベルの人が一番ハマりやすいポイントだと思うので、同じ轍を踏む人の参考になれば嬉しいです。

## 1. 何が起きたか ― 1行JSONと貪欲マッチの出会い

ガードの仕組みはシンプルです。Claude CodeのPreToolUseフックが、実行予定のツール呼び出しをJSONで標準入力に流してくれるので、Pythonスクリプト（`/path/to/guard.py`）がそれを受け取り、`tool_name` が `Bash` のときだけ `tool_input.command` を取り出して危険パターンを検査します。

入力されるJSONは、あるときは整形済み（改行・インデントあり）、あるときは**改行のない1行**で届くことがありました。これが事故の舞台です。

```json
{"tool_name": "Bash", "tool_input": {"command": "git push origin main", "description": "rm 系コマンドは使わない前提"}}
```

command を抽出していたコードはこれです。一見、正しそうに見えます。

```python
m = re.search(r'"command"\s*:\s*"(.*)"', stdin_text)
command = m.group(1)
```

しかしこの日、止められたのは `git push origin main` ――まったく無害なコマンドでした。

## 2. 原因の解剖 ― `.*` と `.*?` はどこで違うのか

正規表現の `.*` は**貪欲**で、「条件を満たす限りできるだけ長く」マッチしようとします。パターンの終端にある `"` は「ここで止まれ」という目印のはずでしたが、貪欲な `.*` は文字列中の**最後の** `"` まで一気に進んでから、戻って最初に成立する組み合わせでマッチを確定させます。

短いコードで再現してみましょう。

```python
import re

text = '"command": "git push origin main", "description": "rm 系コマンドは使わない前提"'

re.search(r'"command"\s*:\s*"(.*)"', text).group(1)
# => 'git push origin main", "description": "rm 系コマンドは使わない前提'

re.search(r'"command"\s*:\s*"(.*?)"', text).group(1)
# => 'git push origin main'
```

上の結果が示すとおり、`(.*)` は `description` の値まで「command の中身」として飲み込んでいました。この例では description に書いたメモの「rm」という文字が検査対象に入り込み、`rm` を含むコマンドと判定されてブロックされた、というわけです。

**コマンド本体は無害でも、説明文に危険ワードが出ただけで止まる**――エラーメッセージを見ても「なんで `git push` が危険なの？」となり、気づくまでに時間がかかる類の事故です。

## 3. 修正と再発防止 ― 遅延マッチ、単語境界、テスト41件

### 3.1 抽出側： `.*` を `.*?` に

最小限の修正は、量指定子に `?` を付けて**遅延マッチ（lazy match）**に切り替えることです。`.*?` は「条件を満たす**最短**」でマッチを打ち切るので、値を閉じる最初の `"` で止まります。

ただし `.*?` にも弱点があります。値の中にエスケープされた引用符 `\"` が含まれると、その `"` を閉じと誤認して途中で切れます。値に `\"` が入り得るなら、このパターンがより堅牢です。

```python
# 「" でも \ でもない1文字」または「\ + 任意の1文字」の繰り返し
COMMAND_RE = re.compile(r'"command"\s*:\s*"((?:[^"\\]|\\.)*)"')
```

なお、正道は「JSONは `json.loads()` でパースする」ことです。ただしガードのようなツールは、届く入力が常に厳密なJSONである保証がない場面もあります。実装では `json.loads()` をまず試み、失敗したら上の正規表現にフォールバックする構成にしました。
